# PS Flow 0.7.0（2026-10-20 下载修复）

## 安装与更新

Quicker 使用原来的两个动作：**PS Flow 侧边助手**、**测试 PS Flow 下载包**。首次设置通过精确动作名称调用下载动作，请保留此名称并避免重名。`program.source.yaml` 是开发源码，不能直接当作原生 Quicker 动作导入。

完整离线安装需要将应用、Node 运行包以及可选的本机后端包放在 Install.cmd 同目录，再运行 Install.cmd。在线安装缺失包时，会尝试 Gitee / GitHub 来源。

## 修复内容

- 修复下载动作 C# 回调编译错误，以及跨动作调用未返回安装 JSON 的问题。
- 主动作只使用启动器自带的安装进度窗口，并清理旧版残留窗口。
- 安装结果包含经实际服务健康检查确认的版本和运行模式。
- 卸载只处理所属安装目录内的组件进程；保留个人数据。删除个人数据要求明确确认，失败项目会返回失败状态。
